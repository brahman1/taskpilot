Importer les offres

Chargez le JSON exporté par le compagnon de lecture du portail, ou collez une liste de missions.

Les offres sans coordonnées restent visibles et sont exclues du planning jusqu’à leur correction. L’import fusionne les offres avec votre liste et conserve les statuts suivis. La première importation retire les exemples fictifs.

Accès au portail Taskrabbit

Renseignez l’adresse de votre compte Taskrabbit. Elle peut être différente de votre adresse TaskPilot et sera conservée dans votre profil. La connexion au portail officiel se fait séparément.

Importer les offres réelles

Le dossier portal-reader contient une extension Chrome / Edge à charger en mode développeur. Sur la liste des missions, cliquez sur l’extension pour télécharger les offres, puis importez-les ici.

Le compagnon lit seulement la page ouverte. Il ne clique jamais sur « Demander la Task ». La surveillance nécessite le compagnon associé ; l’envoi des demandes reste manuel.

Demandes à vérifier sur Taskrabbit

Les demandes sont préparées localement, sans envoi. Vérifiez chaque offre sur le portail. Déclarez son envoi seulement après l’avoir réellement demandé ; l’attribution reste à confirmer.

Associer le portail Taskrabbit

Chargez le dossier portal-reader comme extension dans Chrome ou Edge. Ouvrez la liste des offres du portail et connectez-vous vous-même. Collez ce code dans le compagnon, puis activez sa surveillance.

Lecture seule : aucune demande envoyée. Le navigateur et le serveur local doivent rester ouverts. Le code devient invalide à l’arrêt du serveur.
