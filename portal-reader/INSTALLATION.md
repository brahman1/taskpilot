# Connecter TaskPilot à votre portail

1. Décompressez l’archive dans un dossier que vous conserverez.
2. Dans Chrome, ouvrez `chrome://extensions` (dans Edge : `edge://extensions`).
3. Activez le mode développeur, choisissez « Charger l’extension non empaquetée » et sélectionnez ce dossier.
4. Dans TaskPilot, ouvrez **Taskrabbit**, enregistrez votre adresse, puis **Connecter mon portail Taskrabbit**.
5. Ouvrez le portail officiel et connectez-vous vous-même. Restez sur la liste des missions.
6. Dans TaskPilot, obtenez votre code d’association. Dans le compagnon, choisissez **Site public**, collez le code, cochez **Connecter le compagnon**, puis **Appliquer**.
7. Dans TaskPilot, choisissez vos horaires et activez la surveillance. Le compagnon applique automatiquement vos changements.

Gardez le navigateur et la liste Taskrabbit ouverts, et l’ordinateur éveillé. Vous pouvez fermer l’onglet TaskPilot. Pendant les créneaux actifs, la liste est vérifiée toutes les 30 secondes ; le navigateur ou le portail peuvent retarder ces contrôles. Le service ne garantit pas la réception à la seconde.

Le code est privé : ne le partagez pas. Une nouvelle association invalide le précédent. Sur le site public, il expire après 90 jours. En local, il expire à l’arrêt du serveur.

Cette version lit et synchronise les offres. **Elle n’envoie pas de réservation automatique.** Les confirmations et annulations auprès des clients se font dans Taskrabbit.

Pour mettre à jour le compagnon, remplacez les fichiers par ceux de la nouvelle archive puis cliquez sur le bouton de rechargement de l’extension.
